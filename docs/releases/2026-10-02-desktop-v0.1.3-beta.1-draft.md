# 桌面版 v0.1.3-beta.1 發布草稿（未發布，等老闆點頭）

## 這版改了什麼
- 桌面版改連正式網域 `https://huddle.lazy72.com`（v0.1.2 以前寫死舊網域；舊網域永不關，舊版照常可用）。
- 只有正式安裝版會登記 `huddle-desktop://`（PR #132 內容），開發機跑過 desktop:dev 也不會再搶走登入回傳。

## 發布步驟（老闆同意後才做）
1. `gh release create v0.1.3-beta.1 --prerelease --target chore/desktop-0.1.3`（或合併後指 main），上傳兩個 dmg＋SHA256SUMS.txt。
2. Windows：`gh workflow run windows-desktop.yml --ref <同一分支> -f publish=true`（上傳 exe＋WINDOWS-SHA256SUMS.txt 到 `v0.1.3-beta.1`）。
3. release 頁確認三個下載連結 200 後，才合併官網下載連結改動（`components/marketing/marketing-page.tsx`，已在本分支）→ 部署。順序不可反，否則官網連結 404。

## Release notes 草稿（中文）
桌面版改用新網址 huddle.lazy72.com。第一次開新版需要重新登入一次（新舊網址的登入狀態分開保存）。
Mac Apple Silicon 請選 arm64；Intel 請選 x64。尚未完成 Apple 公證；Windows 測試版未簽署，安裝時可能顯示安全提示。請退出舊版後安裝新版。
