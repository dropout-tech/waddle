# 營運與會員介面

## Overview

本文件記錄 2026-09-25 的實裝，是 Huddle 既有陶瓷工作介面的延伸，採 **Operate** 模式：讓使用者查看權益、管理活動、完成表單與核對紀錄。它不是公開官網海報風格的改版，也不修改全域 `DESIGN.md`。產品與視覺依據為 `PRODUCT.md`、`DESIGN.md`；實裝來源為 `components/operations/` 與 `app/globals.css`。

- `/admin`「營運後台」：供已授權管理員查看會員與活動資料、管理優惠碼與贈送時間、查閱推薦／操作紀錄、調整活動、管理公告及查看來源分析。一般會員會看到無權限說明。
- `/membership`「會員與推薦」：供登入會員查看 Pro 使用期限與時間紀錄、產生和分享推薦碼、設定公開化名、兌換優惠碼、補填朋友推薦碼與查看自願公開的排行榜。
- 兩頁都有「回工作空間」入口；管理員可從會員頁進入後台，後台可返回自己的會員頁。

## Colors

沿用 `app/globals.css` 的陶瓷中性色，不另立色票。頁面使用 `--background`／`--foreground`，獨立區塊使用 `--card` 和 `--border`，說明文字使用 `--muted-foreground`。一般按鈕使用 `--secondary`／`--secondary-foreground`；成功訊息使用 `--muted`，錯誤訊息使用 secondary 表面、foreground 文字及邊框。

主要 CTA 與目前選取的營運導覽按鈕使用 **foreground 底色、background 文字**，以既有高對比中性色配對承接可讀性，而非直接將赤陶 primary 當作文字按鈕背景。鍵盤焦點使用 `--ring` 的 2px outline、3px offset。這是來源碼所定義的處理，不能據此宣稱整頁已通過無障礙稽核。

## Typography

繼承 app 字體，不使用官網海報展示字體。頁面基準字級 15px；主標題為 26–36px、650 字重；區塊標題 21px、600 字重；輔助文字與表格為 14px。說明段落行高 1.7，頁首說明最多 65ch。輸入元件為 16px；統計與表格數字採等寬數字排版。

## Layout

頁面使用可垂直捲動的 `100dvh` 主容器，保留安全區邊距，寬螢幕以約 1200px 內容寬度居中。頁首後接操作導覽或會員權益區塊，再呈現表單和紀錄；會員／活動詳情在原區塊下方展開。

後台九個導覽項目依序為：數據總覽、會員、優惠碼、推薦紀錄、訂單與訂閱、操作紀錄、活動設定、公告與通知、來源分析。導覽採可換行的 flex 排列，沒有固定單列寬度；目前項目以 `aria-current="page"` 標記。它是按鈕導覽，未實作 ARIA tablist 的方向鍵切換模式。

桌面會員區塊和共用表單為雙欄，間距分別為 24px 與 18px。700px 以下改成單欄，頁首上下堆疊，左右邊距 16px、區塊內距 18px。總覽數字由四欄改成兩欄。表格保留可水平捲動的容器，操作按鈕列可以換行。

## Elevation & Depth

營運介面的 CSS 以背景、card 表面、暖色邊框及留白區分層次，沒有為這些區塊新增陰影。沿用工作介面的表面語言，不引入官網海報插畫或展示特效。

## Shapes

區塊與輸入元件使用既有 `--radius`；按鈕與訊息框使用 10px 圓角。按鈕與一般輸入控制至少 44px 高；核取方塊本體 19px，外層標籤列至少 44px 高。表單欄位保留可見 label，提示經 `aria-describedby` 關聯。

## Components

### 會員隱私與排行榜

公開排行榜採會員主動勾選的公開設定，使用者可取消公開。介面說明只顯示化名與有效推薦人數，不顯示 Email、頭像或真實姓名；化名欄位要求 2–24 字並提示不要使用聯絡資訊。排行榜最多呈現 100 位，依累積有效推薦人數排序，同人數並列；自己的列另顯示「（你）」。管理員會員明細中的 Email 不屬於公開排行榜。

### 資料與操作狀態

- 載入：顯示轉動圖示與「正在讀取資料…」，使用 `role="status"`。
- 空資料：依情境顯示未領取時間、沒有公開推薦紀錄、尚無符合條件的紀錄等文字；活動暫停有獨立說明，不以假資料填滿版面。
- 錯誤：共用訊息以 `role="alert"` 呈現；主要頁面初始載入失敗提供「重新載入」。具體子區塊的重試能力仍以各元件實裝為準。
- 成功：共用回饋以 `role="status"` 呈現；儲存期間停用相關操作。複製失敗會提示手動選取文字。
- 無權限：後台顯示帳號未獲授權的說明，不呈現管理員導覽及資料內容。

### 指標定義與購買邊界

總覽直接附上指標定義：活躍指新增或修改任務／排程，單純登入不算；統計採台北日期，自功能啟用後收集，不回填私人任務內容。到期體驗會員的「目前付費比例」是當下有效付費權益比例，不是歷史首次付費轉換率；沒有到期樣本時不計算比例。

來源分析以已兌換優惠碼優先、有效推薦次之，其餘為自然註冊；後補優惠碼會更新分類。開始使用指任務或排程寫入；一週留存指註冊滿 8 天且第 6–8 個日曆日有操作。付費欄表示目前有效權益，不表示累積訂單或營收。

**Checkout 與完整訂單金流仍未配置／啟用。**「訂單與訂閱」目前呈現權益同步紀錄與明確的未啟用說明。訂單金額、付款失敗、退款及下一次扣款日不能以推算值補上；贈送天數不能計為營收。會員頁對既有付費權益的描述不代表本次已接通購買流程。

## Do's and Don'ts

- 維持工作介面的溫和文案、現有中性色、表單標籤與明確的操作結果。
- 保留指標定義、活動停用提示與排行榜公開選擇，不把未公開會員補入榜單。
- 不將有效權益、兌換次數或贈送天數描述為營收或已完成付款。
- 不將測試截圖宣稱為真實會員資料或正式營運成果。`scripts/e2e/operations-verify.mjs` 透過模擬回應產生驗證畫面，相關 screenshot artifacts 是 **synthetic／合成測試資料**。
- 本文件依來源碼記錄實裝，不據此宣稱跨裝置畫面、正式環境、深色模式或完整無障礙驗證已通過；相關結論應另附實際驗證證據。
