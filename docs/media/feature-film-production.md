# Huddle 企鵝魔法功能動畫

## 已確認故事

使用者要求一般行事曆顯示在電腦上，周圍貼滿待辦便條；使用原稿企鵝施展魔法，便條紙收進行事曆旁邊，再示範拖曳等重點功能。影片搭配不使用第三方歌曲或取樣的原創配樂。官網保留已選的獨立展覽海報方向。

## 製作方法與研究

採可重現的 Canvas 分鏡動畫與逐格渲染，保留原稿角色、繁中文字和清楚的任務移動路徑。輸出 1920×1080、30fps、18秒 H.264/AAC MP4，配可編修動畫來源及 WAV 配樂。不是直接錄製正式帳號，全部任務是示例。魔法屬於情境轉場，不表示已有相機/OCR或自動解析實體便條紙的功能。

- [Things 官方功能介紹](https://culturedcode.com/things/features/)：借鏡以明確操作展示產品的敘事方法，不將其能力或畫面當成 Huddle。
- [FFmpeg image2 格式文件](https://ffmpeg.org/ffmpeg-formats.html#image2-1)：固定幀率逐格輸出，避免瀏覽器即時錄影掉幀影響節奏。
- [FFmpeg 官方文件](https://ffmpeg.org/ffmpeg.html)：以常见瀏覽器支援的H.264/yuv420p與AAC合成，faststart方便網路播放。

## 敘事與動態重點

1. 多張便條圍住日曆：同時做很多事，資訊散落四周。
2. 原稿企鵝出場、施法：視線沿弧線與紙張的連續移動進入畫面。
3. 紙張收進側欄：每件事保留其文字和顏色，讓觀眾看懂前後對應。
4. 游標拖曳：任務進時間格，落位後出現時間區塊。
5. 調整、完成与專注：呈現下一步操作，收尾回到產品名與品牌口號。

音畫有節奏地同步，不用全屏閃光或頻閃。播放器不自動出聲、有暫停和重播。頁面另提供文字摘要與情境示意標記。

## 再製

```sh
python3 scripts/media/compose-huddle-score.py
node scripts/media/render-feature-film.mjs
```
