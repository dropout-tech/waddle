# Resend 寄信網域設定操作手冊（老闆本人操作，約 20 分鐘）

用途：讓 Huddle 用 `billing@lazy72.com`（名稱可再改）寄收據、年繳續訂前 7 天提醒、扣款失敗通知、退款完成通知——這些是服務條款已承諾的信。
費用：Resend 免費方案 $0（每月 3,000 封、每天 100 封、可用自訂網域）。量大再升 Pro US$20／月。以 https://resend.com/pricing 當下頁面為準。

## 先知道的三件事
1. lazy72.com 的 DNS 在 **Cloudflare** 管（2026-10-02 實查 NS＝`desi.ns.cloudflare.com`、`carmelo.ns.cloudflare.com`）。要去 Cloudflare 後台加紀錄。
2. 你現在的信箱在 **Gandi**（根網域 MX＝`spool.mail.gandi.net`、SPF＝`v=spf1 include:_mailcust.gandi.net ?all`）。**這兩筆完全不要動**。Resend 要的紀錄都掛在子網域 `send` 與 `resend._domainkey` 底下，名稱不同、互不干擾（2026-10-02 實查這兩個名稱目前都沒有紀錄，可直接新增）。
3. 下面的「值」只是長相範例，**一定要以 Resend 後台顯示的為準**（金鑰每個帳號不同）。

## 步驟
1. 到 https://resend.com 用你的 Email 註冊（建議用你自己會長期使用的信箱）。
2. 左側 **Domains → Add Domain**，輸入 `lazy72.com`，Region 選預設即可 → Add。
3. Resend 會列出約 3 筆紀錄，長相如下：

   | 類型 | 名稱（Name） | 值（Content） | 其他 |
   |---|---|---|---|
   | MX | `send` | `feedback-smtp.<區域>.amazonses.com` | Priority 10 |
   | TXT | `send` | `v=spf1 include:amazonses.com ~all` | |
   | TXT | `resend._domainkey` | `p=MIGfMA0…`（一長串） | |

4. 另開分頁到 Cloudflare → 選 `lazy72.com` → **DNS → Records → Add record**，照 Resend 畫面一筆一筆加。
   - 名稱只填 `send`、`resend._domainkey`（Cloudflare 會自動接上 `.lazy72.com`）。
   - Proxy 狀態一律設成 **DNS only（灰色雲朵）**。
5. 建議再加一筆 DMARC（只監控、不影響寄信）：類型 TXT、名稱 `_dmarc`、值 `v=DMARC1; p=none; rua=mailto:<你收得到信的信箱>`。
6. 回 Resend 按 **Verify DNS Records**，通常幾分鐘到 1 小時內變綠色 Verified。
7. Resend 左側 **API Keys → Create API Key**：名稱 `huddle-billing`、權限選 **Sending access**、Domain 選 `lazy72.com`。
   - 金鑰只會顯示一次。**請不要貼在聊天裡**；等工程端說要設定時，你本人貼進 Supabase 後台的 Edge Function Secrets（名稱 `RESEND_API_KEY`），工程端會給你逐步截圖指引。

## Apple「隱藏我的 Email」的人也要收得到（必做，否則用 Apple 登入且隱藏信箱的客人收不到收據）
1. https://developer.apple.com/account → **Certificates, Identifiers & Profiles** → **More**（或 Services）→ **Sign in with Apple for Email Communication** → **Configure**。
2. 「Email Sources」新增網域：`lazy72.com` 與 `send.lazy72.com`。
3. 新增寄件地址：`billing@lazy72.com`（之後若改寄件地址要回來加）。
4. 狀態要顯示通過（Resend 已處理 SPF／DKIM，照上面做完通常會過）。
（此段依 Resend 整理的說明，Apple 官方頁面路徑若有不同，以 Apple 畫面為準。）

## 做完後告訴工程端
- 「Resend 網域已 Verified」＋寄件地址要用哪個（預設 `billing@lazy72.com`，寄件人名稱「Huddle」）。
- Apple 寄件網域登記狀態。
- 金鑰**不要**給工程端，你自己貼（見步驟 7）。

## 附帶好處
同一個 Resend 帳號之後也能拿來設定 Supabase 的註冊／登入通知信（目前 SMTP 未設的舊問題），屆時另外問你。
