您好，我們是 Huddle（任務管理軟體，個人經營者名義申請），準備用 SHOPLINE Payments 的「內嵌式付款」在官網（https://huddle.lazy72.com）販售軟體訂閱：月繳 NT$150、年繳 NT$990；第一次訂閱可免費試用 2 週，試用需先綁定信用卡，試用結束自動扣第一期，之後每期自動扣款。先前已向您確認個人戶可收 SaaS 訂閱、每月收款無上限，謝謝。以下想再請教技術與作業細節：

**一、開通與資格（★ 最優先）**
1. ★ 我們要怎麼開通「綁卡」與「定期扣款（Recurring）」？需要另外簽約或審核嗎？大約需要多久？需要準備哪些資料？
2. ★ 個人戶（非公司）可以使用綁卡與定期扣款嗎？
3. ★ 定期扣款時（持卡人不在場），被發卡行要求 3D 驗證或 CVC（錯誤碼 4900／4901）的情況常見嗎？如果綁卡時已做過 3D 驗證，之後的定期扣款是否會被視為商店發起交易（MIT）而免 3D？
4. ★ API 呼叫需要 IP 白名單嗎？定期扣款的 `client.ip` 應該填什麼？我們的伺服器在雲端（Supabase），沒有固定 IP。
5. ★ 建立交易時如果網路逾時、沒拿到 tradeOrderId，可以用我們的 referenceOrderId 查詢結果嗎？同一個 referenceOrderId 重送會發生什麼事（回 1001 嗎）？`idempotentKey` 的作用與有效期？
6. ★ 沙盒共用特店帳號是否已開通綁卡與定期扣款？webhook 網址是否共用、會被其他開發者覆蓋？可否申請我們專屬的沙盒帳號？
7. ★ 定期扣款時，`order`、`billing`、`shipping`、`returnUrl` 這些欄位是否必填？我們是線上服務沒有寄送，shipping 該怎麼填？

**二、交易與通知**
8. 定期扣款的建立交易回應，是否一定是最終結果？status／subStatus 的完整列表可以提供嗎？
9. Webhook 簽章 `sign` 是小寫十六進位字串嗎？timestamp 建議容許多少誤差？
10. 綁卡的 1 元授權，持卡人會收到簡訊或在帳單上看到嗎？綁卡是否一定會走 3D 驗證？
11. 卡片到期或換發時，是否有卡號自動更新服務？付款工具狀態改變時會發 `customer.instrument.updated` 嗎？
12. `customerToken` 的有效期多久？
13. API 速率限制是多少？
14. 沙盒「金額為 3 的倍數會走 3D」的規則，是以「元」還是「分」計算？
15. 年繳 NT$990 一次扣款、月繳 NT$150，金額上有沒有上下限？

**三、退款與爭議**
16. 退款可以部分退款嗎？退款時原交易的手續費會退還嗎？退款多久會回到持卡人帳上？退款失敗的常見原因？
17. 持卡人拒付（chargeback）的通知方式與處理流程？每筆拒付是否另收費用？

**四、顯示與合規**
18. 持卡人帳單上顯示的商店名稱是什麼？可以設定成「HUDDLE」嗎？
19. 同一張卡綁在多個會員帳號是否允許？是否提供可辨識「同一張卡」的識別碼（我們想限制每人只能試用一次）？
20. 網站上是否需要放特定的「定期扣款代扣協議」文字？SDK 顯示的 subscribeAgreement 文字內容是什麼？
21. 未來如需開立電子發票，SHOPLINE Payments 有沒有合作方案？
